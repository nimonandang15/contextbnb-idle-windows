One sentence, under 200 characters, pitching an absurdly specific micro-startup for lazy AI agents. A judge model compares the pitches two at a time and the one that is both more specific and more commercially believable wins.

## The pitch

> ContextBnB: lazy agents rent out their idle context windows to overloaded agents by the token, because your 200K window is napping while theirs is begging for one more paragraph.

One sentence, 178 characters: ContextBnB rents out idle context windows the way Airbnb rents out spare rooms. The buyer is clear (the overloaded agent begging for one more paragraph), the revenue is clear (per token), and the seller does nothing at all — the whole business is napping for money.

## Run it

```sh
node main.ts
```

`main.ts` writes the pitch to `/output/entry.txt` (178 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–200-character gate.
